1) Cách deploy backend API:

  Dựa trên các hình ảnh bạn cung cấp, dự án của bạn là một Cloudflare Worker (tên: tlm-affiliate), sử dụng TypeScript và trình quản lý gói pnpm.
  Để deploy lại backend này, bạn thực hiện theo các bước sau:
  
  Bước 1: Mở Terminal tại đúng thư mục dự án
  Đường dẫn của bạn trong ảnh là: C:\TLM\TLM-Affiliate\code\apps\worker.
  Bạn cần mở Command Prompt (CMD), PowerShell hoặc Terminal trong VS Code tại thư mục worker này (nơi có file wrangler.toml).
  
  Bước 2: Đăng nhập vào Cloudflare (Nếu chưa làm)
  Nếu bạn đã lâu không deploy hoặc đổi máy, hãy chạy lệnh sau để đăng nhập:

    pnpm wrangler login
  
  Một trang web sẽ hiện ra, bạn chỉ cần nhấn Allow để cấp quyền.
  
  Bước 3: Kiểm tra file cấu hình (Tùy chọn)
  Trong thư mục của bạn có file wrangler.toml. Hãy đảm bảo tên định danh (name) trong file đó khớp với tên tlm-affiliate trên dashboard Cloudflare của bạn.
  
  Bước 4: Chạy lệnh Deploy
  Vì bạn dùng pnpm, hãy chạy lệnh sau:

    pnpm wrangler deploy
  
  (Lưu ý: Nếu bạn đang dùng phiên bản Wrangler cũ, lệnh có thể là pnpm wrangler publish, nhưng hiện tại Cloudflare khuyến khích dùng deploy).
  Các trường hợp lưu ý khác:
  Nếu bạn có sử dụng Secret (Biến môi trường bảo mật):
  Trong ảnh dashboard của bạn có các secret như SESSION_SECRET, DODO_WEBHOOK_SECRET. Nếu bạn thêm code mới cần secret mới, hãy dùng lệnh:

    pnpm wrangler secret put TEN_BIEN_CUA_BAN
  
  Nếu bạn muốn xem log trực tiếp để debug:
  Sau khi deploy, nếu muốn xem lỗi khi gọi API, hãy chạy:

    pnpm wrangler tail
  
  Kiểm tra trên GitHub:
  Tôi thấy bạn vừa merge code trên GitHub 17 phút trước. Đừng quên chạy git pull để lấy code mới nhất về máy local trước khi chạy lệnh pnpm wrangler deploy nhé.
  Tóm lại: Chỉ cần mở Terminal tại thư mục worker và gõ: pnpm wrangler deploy là xong!
